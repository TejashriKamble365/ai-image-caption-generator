# AI Image Caption Generator Using BLIP

This is a free deployment of the **AI Image Caption Generator Using Salesforce BLIP & Generative AI** hosted on Hugging Face Static Spaces.

## Features
- Upload JPG or PNG images.
- Generate automatic captions with Salesforce BLIP.
- Text-to-Speech audio narration for visually impaired accessibility.
- Hyperparameter controls (Beam search, length limits, prompt conditioning).
- Copy to clipboard & export diagnostics report.
